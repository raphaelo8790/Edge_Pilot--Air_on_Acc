# `datasets/vision-benchmark/` - the reference vision dataset

**Work package:** vision benchmark.

## What this folder is

A synthetic construction-safety dataset: 21 samples across seven labels -
`hardhat`, `safety_vest`, `gloves`, `goggles`, `mask`, `ladder`,
`safety_cone`.

Synthetic on purpose. The images are generated from a committed script rather
than collected, which means the dataset has no licensing question, no privacy
question, and no person in it - and it can be regenerated byte-identically on
any machine. `manifest.json` records a SHA-256 so a run can prove which version
of the dataset it measured.

## What happened here

The dataset is unchanged. The measurement taken against it is new, and it is
worth recording here because this is where a reader will come looking for it:
`llava:latest` scored **66.7% accuracy** on these 21 samples - 14 correct - and
**failed** the workload's own 0.80 accuracy gate. The per-class matrix closes
exactly: all three `hardhat` samples were classified as `safety_cone`, giving
`hardhat` an F1 of 0.0 while `safety_cone` picked up three false positives.
Two gloves and two masks were also called hardhats.

The `images/` subfolder is generated and git-ignored. `npm run vision:fixtures`
rebuilds it, and both `prebuild` and `pretest` call that automatically, so it
is never a missing prerequisite.
