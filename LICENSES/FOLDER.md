# `LICENSES/` - the full licence texts

**Work package:** shared.

## What this folder is

The verbatim text of both licences this repository is under. `LICENSE` at the
root states which covers what; these are the documents it refers to.

## What happened here

The project moved from MIT to **AGPL-3.0-or-later** for the work added after
the imported baseline. Two texts are needed rather than one, because two
bodies of work are present and neither licence can speak for the other.

The AGPL text was fetched from the Free Software Foundation rather than typed
out. A licence is only enforceable if its wording is exact, so reproducing one
from memory is not a shortcut - it is a defect with legal consequences.

## Files

| File | What it is |
|---|---|
| `AGPL-3.0.txt` | 661 lines, verbatim from gnu.org. Covers the work added after the baseline commit |
| `MIT.txt` | The original notice, preserved unchanged. MIT's single condition is that it travels with copies of the software, so it stays for as long as any baseline file remains |
